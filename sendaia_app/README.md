# sendaia_app

Aplicación Flutter de **SendaIA**: apoyo parental en el aprendizaje de niños con TDAH
(Centro Colibrí, 2026).

> El nombre técnico del paquete se mantiene como `rimai_app` en `pubspec.yaml`
> (importaciones `package:rimai_app/...`); solo cambió la carpeta.

## Getting Started

- `flutter pub get`
- `flutter run`
- `flutter analyze` / `flutter test`

Para más ayuda: [Flutter docs](https://docs.flutter.dev).
